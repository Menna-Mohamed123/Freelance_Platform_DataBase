# Freelance Platform Database 🚀💻

## About The Project
A complete database for a freelance platform (similar to Upwork) that connects clients with freelancers. This project was built to serve as a robust, secure, and scalable Data Layer.

## Key Features
* **Smart Search:** Fast and accurate project search using **Stored Procedures**.
* **Workflow Automation:** Auto-updating project statuses upon contract creation using **Triggers**.
* **Financial Calculations:** Automated platform fee calculations using **User-Defined Functions**.
* **Safe Operations:** Secure contract cancellation with rollback mechanisms using **Transactions** to prevent data inconsistency.
* **Admin Dashboard:** A quick summary of contracts and platform data using **Views**.
* **Data Integrity:** Strict rules to prevent invalid entries (e.g., negative amounts) using **Check Constraints**.

## Tech Stack
* Microsoft SQL Server
* T-SQL (Advanced Database Concepts)
